# Generative AI – From Fundamentals to Advanced Applications

A source-grounded Generative AI learning hub created with **Google NotebookLM** as part of the BSERC Generative AI Internship.

## Project overview
This project organizes learning across eight modules, from foundational concepts to advanced applications. NotebookLM was used to explore a curated collection of research papers, official documentation, learning resources, and educational videos, then generate study materials grounded in those sources.

> **Scope note:** This is a research and learning resource built with NotebookLM. It is not a newly trained or fine-tuned AI model.

## Learning modules
1. Introduction to Generative AI
2. Foundations: neural networks, tokens, tokenization, and embeddings
3. Transformers: attention, self-attention, and architecture
4. Large Language Models: pretraining, fine-tuning, and inference
5. Prompt Engineering: zero-shot, few-shot, and structured prompts
6. Retrieval-Augmented Generation (RAG): retrieval, chunking, embeddings, and vector databases
7. Advanced GenAI: AI agents, tool calling, multimodal AI, and agentic workflows
8. Applications, limitations, ethics, hallucinations, and future directions
